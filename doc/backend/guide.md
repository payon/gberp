# Guide — 사용자 가이드 (운영 매뉴얼)

> 버전: v0.2.1 · 갱신일: 2026-09-28

## 1. 접속·로그인

- URL: `http://localhost:3000` (개발) / `http://rustkorea.cloud:3400` (운영)
- 로그인: 이메일 + 비밀번호
- 시드 계정(비밀번호 `SEED_PASSWORD` 환경변수 또는 기본 `admin1234`, 운영 시 반드시 변경):

| 역할 | 이메일 |
|---|---|
| 최고관리자 | admin@example.com |
| 관리자 | manager@example.com |
| 영업사원 | sales@example.com |
| 운영자(OP) | op@example.com |
| 기사 1 | driver1@globe.com |
| 기사 2 | driver2@globe.com |
| 가이드 | guide1@globe.com |

## 2. 첫 설정(관리자)

1. **업체 설정 > 업체 정보**: 회사명·사업자등록번호·대표자·전화·주소·로고 업로드
1-1. **업체 설정 > 앱 아이콘**: PWA 이름·테마색 + 원본 이미지 업로드 → 데스크탑/모바일/태블릿 아이콘 자동 생성
2. **업체 설정 > 알림·음성**: 기본 음성 속도, 자동 음성 안내 기본값
3. **업체 설정 > 배차 규칙**: 기본 휴게 시간(기본 8시간)
4. **업체 설정 > 휴일**: 공휴일·자체 휴일 등록(배차 경고 + 기사앱 배너)
5. **업체 설정 > 문서**: 계약서/견적서/운행표 샘플 규격서 업로드
6. **업체 설정 > 기능**: 필요한 기능 켜기(반자동 배차는 기본 ON)

## 3. 기본 업무 흐름

```
사용자 등록 → 고객 등록 → 상품 등록 → 견적/계약 → 일정 등록 → 배차 배정
   배차 확인(기사앱) → 운행 시작/종료 → 운행일지 → 자동 정산 초안 → 정산 승인/지급
```

### 3.1 배차하기 (수동)
1. 상품 관리에서 상품 생성
2. 일정 관리에서 일정 생성(출발/도착/인원/기간)
3. 배차 관리에서 일정 선택 → 차량/기사/가이드 배정 → 예정 출발·도착 입력
   - 같은 기사 중복 시간대면 자동 차단
   - 휴일·휴게 부족이면 경고 배지로 표시

### 3.2 반자동 배차 (추천)
1. 배차 관리 > "반자동 배차" 버튼
2. 일정 선택(배차 없는 일정만 가능) → "추천 받기"
3. 기사·차량 후보(점수+사유)에서 조합 선택
4. "이 조합으로 등록" → PENDING 배차 생성(확정 전 운영자 확인)
5. 배차 목록에서 상태를 CONFIRMED로 변경 권장

### 3.3 기사앱(모바일)
1. `/login` 접속 → 기사 계정 로그인
2. 오늘 배차에서 "운행 시작" → 운행 중
3. 종료 시 (운행일지 기능 ON이면) 종료 주행거리·특이사항 입력 → "운행 종료"
4. 음성: "전체 음성 안내 듣기" / 자동 안내 스위치

### 3.4 정산
- 자동 초안: 운행 종료 시 PENDING 정산 생성(금액 미입력)
- 정산 관리에서 금액(기본/야근/상여/공제) 입력 → 승인 → 지급일 기재
- 수동 생성도 가능(기사/가이드/외주업체)

## 4. 엑셀 사용

- **내보내기**: 목록 화면에서 엑셀 다운로드(헤더=한글 라벨)
- **일괄 등록**(기능 ON 시): 위에서 받은 엑셀 파일을 그대로 수정해 업로드
  - 동일 헤더 유지(삭제 금지), 필수 열(별표) 채우기
  - 실패 행은 행 번호와 사유로 반환(부분 성공 허용)

## 5. 알림·운영 알림

- SMS 자동 발송(기능 ON + 게이트웨이 URL 설정 시): 배차 생성 즉시 기사·가이드에게 문자
- 대시보드 운영 알림(기능 ON): 정산 대기·차량 보험/검사 만료·기사 면허 만료·오늘 배차 현황
- 웹 푸시: 브라우저/설치앱에서 구독 시 새 배차 수신

## 6. 자주 묻는 질문 (FAQ)

| Q | A |
|---|---|
| 추천 버튼이 없어요 | 기능 OFF → 설정 > 기능 > 반자동 배차 켜기 |
| 배차 추천이 409에요 | 이미 배차가 있는 일정 → 다른 일정 선택 |
| 종료 시 운행일지 화면이 나와요 | runLog ON 상태 → 주행거리 입력 후 종료 |
| 정산이 자동 생성 안 돼요 | autoSettlement OFF → 켜기. 이미 종료된 배차는 수동 정산 |
| 엑셀 등록이 "필수 입력"으로 실패 | 헤더가 내보내기와 동일한지 확인(라벨 일치) |
| SMS가 안 와요 | smsNotify ON + 게이트웨이 URL 확인(비어 있으면 큐 기록만 됨) |
| 차량 만료가 안 보여요 | vehicleExpiry + dashboardAlert 둘 다 켜기 |
| 로그인이 잠겼어요 | 15분 후 자동 해제. 관리자면 사용자 화면에서 계정 확인 |

## 7. 관리자 전용

- 사용자/권한: 역할별 메뉴는 자동 필터. **메뉴 권한 탭**(최고관리자만 변경)에서 역할별 메뉴 차단 가능 — 차단은 사이드바+API 동시 적용
- 기사(`/driver`)·가이드(`/guide`) 앱은 교차 접근 불가. 관리자는 미리보기 가능
- 감사 로그: 액션/테이블/검색어 필터, 어떤 누가 무엇을 했는지 확인
- 통계/리포트: 대시보드 카드·최근 배차·계약 대시보드
- 업체 설정: 저장 시 전체 즉시 반영(브라우저 새로고침 필요 시)
