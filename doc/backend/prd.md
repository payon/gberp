# PRD — 종합여행사 ERP (Backend)

> 버전: v0.2.0 · 갱신일: 2026-09-17
> 이 문서는 `doc/backend/` 시리즈의 요구사항 정의서(PRD)이며, 구현된 실제 코드(Next.js App Router + Prisma + SQLite)를 기준으로 작성됐습니다.

---

## 1. 제품 개요

- **제품명**: 종합여행사 ERP (GBERP)
- **대상**: B2B/B2C 여행사 및 관공서·학교·기업 수송 사업자
- **핵심 업무**: 고객/거래처 관리 → 상품 관리 → 일정/계약 관리 → 배차 관리(기사·차량 배정) → 운행일지 → 정산 관리 → 회계 관리 → 더존 연동
- **사용자**: 최고관리자(SUPER_ADMIN), 관리자(ADMIN), 영업사원(SALES), 운영자(OPERATOR), 기사(DRIVER), 가이드(GUIDE)

## 2. 사용자 스토리 (역할별)

| 역할 | 주요 수행 업무 |
|---|---|
| 최고관리자 | 사용자·권한, 업체 설정, 감사 로그 열람, 회계/정산 최종 승인 |
| 관리자 | 모든 업무(고객, 상품, 일정, 계약, 배차, 정산), 설정 변경, 엑셀 등록 |
| 영업사원 | 고객·견적·계약, 일정, 배차(확인), 통계 리포트 |
| 운영자(OP) | 일정·배차, 차량/기사/가이드 배정, 반자동 배차 추천 사용 |
| 기사 | 앱에서 본인 배차 확인, 운행 시작/종료, 음성 안내, 운행일지 |
| 가이드 | 앱에서 본인 배차 확인, 운행 시작/종료 |

## 3. 기능 요구사항 (F → 1.x)

### F1 인증/권한
- F1.1 이메일+비밀번호 로그인 (JWT 세션, 12시간)
- F1.2 역할(Role) 기반 접근 제어: 메뉴/모듈 단위 허용 (hasRole)
- F1.3 계정당 로그인 실패 8회/15분 시 잠금 (인메모리)
- F1.4 직원 목록 화면만 접근 권한 필터 (엑셀 내보내기는 `_all` 직원만)

### F2 CRM (고객/거래처)
- 고객 유형: 개인 / 관공서 / 학교 / 기업
- 관공서용 공문 명칭(문서명), 사업자번호, 담당 영업사원 배정
- 여신 한도/현 잔액 필드 (추가 구현 가능 영역)

### F3 상품/일정/계약
- 상품 유형: 패키지/단체관광/출퇴근/전세
- 일정: 일자, 출발/도착지, 인원, 상태, 특이사항
- 계약: 계약번호 자동 계열(`C-…`), 계약금/잔금 납부, 항목 내역(JSON)
- 계약/일정/배차 연계 구조

### F4 배차 관리
- F4.1 일정에 기사·차량·가이드 배정, 중복 배차 생성 차단(409)
- F4.2 휴일 배차 경고, 휴게시간(기본 8h) 부족 경고 추가
- F4.3 **반자동 배차 추천** (기본 ON): 시간→적합 기사/차량 5순위 추천
- F4.4 정차(stops) 경로 등록, 특별조건(JSON)
- F4.5 월별 조회(`?month=YYYY-MM`)

### F5 운행일지 + 자동 정산 (기본 OFF)
- 기사가 운행 종료 시 주행거리/특이사항/이슈 기록
- 종료 시 DRIVER/GUIDE 정산 초안(PENDING) 자동 생성 (배차당 1회, 중복 방지)
- 정산번호 `S-YYYYMMDD-NNN` 자동 생성

### F6 차량 만료 관리 (기본 OFF)
- 보험 만료일, 정기 검사 만료일 등록/표시
- 대시보드 운영 알림에 반영 (만료/30일 이내)

### F7 엑셀 일괄 등록/내보내기
- F7.1 목록 화면 엑셀 내보내기 (헤더 = 정의된 열 라벨)
- F7.2 엑셀 일괄 등록 (기본 OFF): 내보내기 형식 그대로 업로드 → 필수값 검증 → 일괄 생성
- F7.3 엑셀 셀 수식 주입 방지 (`=`, `+`, `-`, `@` 접두 앞에 `'` 추가)

### F8 대시보드 운영 알림 (기본 OFF)
- 정산 대기 건수, 차량 보험/검사 만료·임박(30일), 기사 면허 만료·임박, 오늘 배차 현황

### F9 알림(SMS/Push/음성)
- F9.1 배차 생성 시 기사/가이드 SMS 자동 발송 (기본 OFF, 게이트웨이 URL 플레이스홀더 치환)
- F9.2 웹 푸시 구독/발송 (VAPID)
- F9.3 기사앱 음성 안내 (TTS): 전체/자동 안내, 기본 속도 0.95
- F9.4 NotificationQueue 중심 비동기 알림 큐

### F10 시스템 설정
- 회사 정보(로고 업로드/삭제), 음성 기본값, 배차 규칙(휴게시간), 휴일 목록, 문서(규격서 업로드), **기능 토글**
- 기능 토글: `semiAutoDispatch(runLog/vehicleExpiry/autoSettlement/excelImport/dashboardAlert/smsNotify)` — 키/값 whitelist 저장

## 4. 비기능 요구사항 (NF)

| ID | 항목 | 요구 |
|---|---|---|
| NF1 | 기술 스택 | Next.js 16 (App Router), React 19, Prisma 6, SQLite, Tailwind v4, shadcn/ui |
| NF2 | 성능 | 목록 조회 500건 limited(`?all=1` take 500), 대시보드 병렬 쿼리(Promise.all) |
| NF3 | 보안 | bcrypt 비밀번호 해시, JWT 세션, 역할 기반 RBAC, 감사 로그, 안전한 파일명 |
| NF4 | 확장성 | 리소스 정의(ResourceDef) 기반 CRUD — 새 모듈 추가 시 `resources.ts`에 정의 |
| NF5 | 운영성 | standalone 빌드, Tauri 데스크톱 래핑(Windows), PWA 오프라인 |
| NF6 | 다국어 | 화면 한글, 내부 코드 영어(enum) |
